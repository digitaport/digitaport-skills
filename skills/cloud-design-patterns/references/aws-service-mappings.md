# AWS Service Mappings

## Common AWS Services per Pattern

- **Message Queue**: Amazon SQS, Amazon SNS, Amazon MQ
- **Cache**: Amazon ElastiCache, Amazon CloudFront, API Gateway caching
- **API Gateway**: Amazon API Gateway, Application Load Balancer
- **Identity**: AWS Identity and Access Management (IAM), Amazon Cognito
- **Configuration**: AWS AppConfig, AWS Systems Manager Parameter Store, AWS Secrets Manager
- **Storage**: Amazon S3, Amazon DynamoDB, Amazon EFS, Amazon RDS
- **Compute**: AWS Lambda, Amazon ECS, AWS Fargate, Amazon EKS, Amazon EC2
- **Event Streaming**: Amazon EventBridge, Amazon Kinesis, Amazon MSK
- **CDN**: Amazon CloudFront
